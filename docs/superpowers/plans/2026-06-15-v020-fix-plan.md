## Absolute Soundness Invariant (SI)

When planner emits a plan at a call-site, the transformed program must be observationally equivalent to the original:
- receiver expression evaluation count identical
- each argument expression evaluation count identical
- evaluation order preserved (receiver → args, left → right)
- return value, exceptions, side-effects all identical

Closedness is necessary but not sufficient. Planner must have an explicit EvaluationSafety step.

"""Verdict key collision: CLOSED+OPEN same method_key → 0 plans regardless of order."""
from flatten.contracts import ClosureVerdict, ClosureStatus
from flatten._cli_orchestration import _verdicts_from_observations
from flatten.observations import ObservationRecord, type_ref, FunctionRef

def _make_obs(cls, qualname):
    return ObservationRecord(
        call_site_id="test:1:0",
        receiver_type=type_ref(cls),
        resolved_function=FunctionRef(module="__main__", qualname=qualname),
        method_name=qualname.rsplit(".", 1)[-1],
        frame_module="__main__",
        order=1,
        qualname=qualname,
    )

def test_verdict_collision_closed_then_open():
    """CLOSED then OPEN → OPEN wins (conservative), 0 plans."""
    class A:
        def run(self): return "a"
    class B:
        def run(self): return "b"
    obs = [_make_obs(A, "A.run"), _make_obs(B, "A.run")]
    verdicts = _verdicts_from_observations(obs)
    # Both observations claim qualname A.run — if system gives CLOSED for one
    # and OPEN for the other, result must be ≤ OPEN
    for v in verdicts:
        assert v.status != ClosureStatus.CLOSED or not v.known_impls, \
            f"Expected non-CLOSED verdict when collision, got {v.status}"

def test_verdict_collision_open_then_closed():
    """Order independent: OPEN then CLOSED → still OPEN, 0 plans."""
    class A:
        def run(self): return "a"
    class B(A):
        def run(self): return "b"  # subclass, so closure is OPEN
    obs = [_make_obs(B, "A.run"), _make_obs(A, "A.run")]
    verdicts = _verdicts_from_observations(obs)
    for v in verdicts:
        if v.method_qualname == "A.run":
            assert v.status in {ClosureStatus.OPEN, ClosureStatus.UNKNOWN, ClosureStatus.UNSAFE}, \
                f"Expected non-CLOSED verdict for open hierarchy, got {v.status}"

## Phase 1: EvaluationSafety (planner.py)

Add `EvaluationSafety` class that enforces the strategy table. Remove the plain-guarded fallback for non-identifier receivers with ≥2 impls in comprehension/lambda.

Strategy table:
| receiver    | impls | context                    | strategy        |
|-------------|-------|----------------------------|----------------|
| identifier  | 1     | any                        | direct         |
| identifier  | ≥2    | any                        | guarded        |
| non-ident   | 1     | any                        | direct         |
| non-ident   | ≥2    | return/assign/expr_stmt    | guarded_temp   |
| non-ident   | ≥2    | comp/lambda/other          | **REFUSE**     |

No guarded_temp→guarded fallback. Refuse with `REFUSED_RECEIVER_REEVAL`.
